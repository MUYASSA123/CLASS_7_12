02

الرسم والحركة مع Turtle

استيراد المكتبة، إنشاء السلحفاة، الحركة، الدوران وخصائص القلم.

مثال 1 — خط

import turtle
t = turtle.Turtle()
t.forward(100)

مثال 2 — مربع

import turtle
t = turtle.Turtle()
t.forward(80)
t.right(90)
t.forward(80)
t.right(90)
t.forward(80)
t.right(90)
t.forward(80)

مثال 3 — خصائص

import turtle
t = turtle.Turtle()
t.pensize(4)
t.forward(100)
t.stamp()
تمارين Turtle تفحص وجود الأوامر الأساسية. بعد نجاح الفحص شغّل الكود في بيئة Python لرؤية الرسم.

✍️ جرّب بنفسك

اكتب كودًا ينشئ Turtle ويرسم خطًا طوله 100.

✍️ جرّب بنفسك

اكتب كودًا يرسم مربعًا باستخدام أربع حركات طولها 80 ودوران 90 درجة.

04

الشروط والمنطق

if وelse والمقارنات وand وor.

مثال 1

age = 13
if age >= 12:
    print("Allowed")

مثال 2

grade = 75
if grade >= 60:
    print("Pass")
else:
    print("Fail")

مثال 3 — and

age = 14
has_card = True
if age >= 13 and has_card:
    print("Enter")

✍️ جرّب بنفسك

استقبل عددًا. إذا كان 10 أو أكثر اطبع Big، وإلا Small.

✍️ جرّب بنفسك

استقبل علامة. إذا كانت 60 أو أكثر اطبع Pass، وإلا Fail.

✍️ جرّب بنفسك

استقبل عمرًا. إذا كان بين 13 و18 شاملًا اطبع Teen، وإلا Other.

07

مدخل إلى الصور ومعالجتها

الصورة كبيانات، الأبعاد، التدوير والتحويل إلى رمادي.

فتح صورة

from PIL import Image
img = Image.open("photo.jpg")
print(img.size)

تدوير

from PIL import Image
img = Image.open("photo.jpg")
rotated = img.rotate(90)
rotated.save("rotated.jpg")

رمادي

from PIL import Image
img = Image.open("photo.jpg")
gray = img.convert("L")
gray.save("gray.jpg")
هذا القسم يشرح أساسيات معالجة الصور كما تظهر في مسار الصف السابع. المختبر التفاعلي للصور سيضاف لاحقًا.
08

مشروع وتحديات

دمج المتغيرات والشروط والحلقات والدوال في مشروعات صغيرة.

🎯 لعبة التخمين

from random import randint
secret = randint(1, 10)
guess = int(input("Guess: "))
if guess == secret:
    print("Correct")
else:
    print("Try again")

🔢 تحدي الرقم الثلاثي

n = 485
a = n // 100
b = (n // 10) % 10
c = n % 10
print(a**2 + b**2 + c**2)

الناتج للعدد 485 هو 105.

🐢 تحدي الرسم

قسّم الشكل إلى خطوات صغيرة ثم اكتب برنامج Turtle يرسمه.

🏆 تحدي نهائي

اكتب برنامجًا يستقبل ثلاث علامات، يحسب المتوسط، ثم يطبع Excellent إذا كان المتوسط 90 فأكثر، Pass إذا كان 60 فأكثر، وإلا Fail.

طريقة التعلم

1. اقرأافهم الشرح بالعربية.
2. شاهدراجع أكثر من مثال.
3. اكتبجرّب الحل بنفسك.
4. افحصاعرف أين أخطأت.
