01

الأساسيات — الطباعة والمتغيرات والاستقبال

نتعلم كيف نطبع المعلومات، نعرّف المتغيرات، نغيّر قيمها، ونستقبل أعدادًا صحيحة وعشرية ونصوصًا من المستخدم.

🧠 قبل أن نكتب الكود

  • الخوارزمية: خطوات مرتبة لحل مشكلة أو تنفيذ مهمة.
  • البرنامج: مجموعة أوامر يكتبها المبرمج ليقوم الحاسوب بتنفيذها.
  • التسلسل: تنفَّذ الأوامر من الأعلى إلى الأسفل، إلا إذا غيّرنا مسار التنفيذ بأمر آخر.
  • التعليق: نستخدم # لكتابة ملاحظة لا ينفذها Python.

مثال 1 — طباعة نص

print("Hello Python")

الأمر print() يعرض المعلومات على الشاشة.

مثال 2 — طباعة رقم

print(25)
print(7 + 3)

يمكن طباعة رقم أو نتيجة عملية حسابية.

مثال 3 — طباعة عدة أسطر

print("Maya")
print(13)
print("Grade 7")

كل أمر print() يطبع في سطر جديد.

مثال 4 — طباعة عدة قيم

name = "Maya"
age = 13
print(name, age)

الفاصلة داخل print() تفصل بين القيم.

مثال 5 — النص مع \n

print("I\nLove\nPython")

\n تعني الانتقال إلى سطر جديد.

مثال 6 — التعليق

# This is a comment
print("Start")

السطر الذي يبدأ بـ # لا يتم تنفيذه.

مثال 7 — تعريف متغير

age = 13
name = "Ali"
height = 1.55

نضع قيمة داخل متغير باستخدام علامة =.

مثال 8 — تعويض قيمة جديدة

age = 13
age = 14
print(age)

يمكن إعطاء المتغير قيمة جديدة، والقيمة الجديدة تحل محل القديمة.

مثال 9 — عدد صحيح int

age = 13
print(age)

العدد الصحيح مثل 13 لا يحتوي على فاصلة عشرية.

مثال 10 — عدد عشري float

height = 1.55
print(height)

العدد العشري مثل 1.55.

مثال 11 — نص str

name = "Maya"
print(name)

النص يوضع بين علامات اقتباس.

مثال 12 — استقبال عدد صحيح

age = int(input())
print(age)

input() يستقبل نصًا، لذلك نستخدم int() عندما نريد عددًا صحيحًا.

مثال 13 — استقبال عدد عشري

height = float(input())
print(height)

نستخدم float() عندما تكون القيمة عددًا عشريًا.

مثال 14 — استقبال نص

name = input()
print(name)

لا نحتاج إلى تحويل عندما نريد استقبال نص.

مثال 15 — استقبال ثم حساب

num = int(input())
print(num + 10)

نستقبل العدد، نخزنه في متغير، ثم نستخدمه في عملية حسابية.

مثال 16 — استقبال أكثر من قيمة

age = int(input())
height = float(input())
name = input()
print(age)
print(height)
print(name)

يمكن استقبال قيم من أنواع مختلفة، كل قيمة في سطر إدخال مستقل.

✍️ سؤال 1 — أوامر الطباعة

اكتب برنامجًا يطبع اسم Maya ثم العمر 13، كل قيمة في سطر منفصل.

✍️ سؤال 2 — الانتقال إلى سطر جديد

استخدم أمر print() واحدًا فقط لطباعة I وLove وPython، كل كلمة في سطر.

✍️ سؤال 3 — تعريف متغير وتعويض قيمة

عرّف المتغير age بقيمة 13، ثم أعطه القيمة 14، وفي النهاية اطبع قيمته.

✍️ سؤال 4 — استقبال عدد صحيح

استقبل عددًا صحيحًا من المستخدم باستخدام int(input())، ثم اطبعه. عند الفحص سيعطيك الموقع العدد 13.

✍️ سؤال 5 — استقبال عدد عشري

استقبل عددًا عشريًا باستخدام float(input())، ثم اطبعه. عند الفحص سيعطيك الموقع 2.5.

✍️ سؤال 6 — استقبال نص

استقبل اسمًا كنص باستخدام input()، ثم اطبعه. عند الفحص سيعطيك الموقع Maya.

✍️ سؤال 7 — استقبال عدد واستخدامه

استقبل عددًا صحيحًا، أضف إليه 10، ثم اطبع الناتج. عند الفحص سيدخل الموقع العدد 13، لذلك الناتج المطلوب 23.

✍️ سؤال 8 — استقبال قيم من أنواع مختلفة

استقبل ثلاث قيم بالترتيب: عدد صحيح، عدد عشري، ثم نص. اطبع القيم الثلاث كل واحدة في سطر.

✍️ سؤال 9 — فهم قيمة المتغير

ما الذي سيطبعه البرنامج؟ لا تستخدم آلة حاسبة؛ اكتب الكود ثم افحصه.

x = 5
x = x + 3
x = x + 10
print(x)

إذا فهمت أن التعويض يغيّر القيمة المخزنة في المتغير، ستعرف النتيجة.

02

الرسم والحركة مع Turtle

استيراد المكتبة، إنشاء السلحفاة، الحركة، الدوران وخصائص القلم.

مثال 1 — خط

import turtle
t = turtle.Turtle()
t.forward(100)

مثال 2 — مربع

import turtle
t = turtle.Turtle()
t.forward(80)
t.right(90)
t.forward(80)
t.right(90)
t.forward(80)
t.right(90)
t.forward(80)

مثال 3 — خصائص

import turtle
t = turtle.Turtle()
t.pensize(4)
t.forward(100)
t.stamp()
تمارين Turtle تفحص وجود الأوامر الأساسية. بعد نجاح الفحص شغّل الكود في بيئة Python لرؤية الرسم.

✍️ جرّب بنفسك

اكتب كودًا ينشئ Turtle ويرسم خطًا طوله 100.

✍️ جرّب بنفسك

اكتب كودًا يرسم مربعًا باستخدام أربع حركات طولها 80 ودوران 90 درجة.

04

الشروط والمنطق

if وelse والمقارنات وand وor.

مثال 1

age = 13
if age >= 12:
    print("Allowed")

مثال 2

grade = 75
if grade >= 60:
    print("Pass")
else:
    print("Fail")

مثال 3 — and

age = 14
has_card = True
if age >= 13 and has_card:
    print("Enter")

✍️ جرّب بنفسك

استقبل عددًا. إذا كان 10 أو أكثر اطبع Big، وإلا Small.

✍️ جرّب بنفسك

استقبل علامة. إذا كانت 60 أو أكثر اطبع Pass، وإلا Fail.

✍️ جرّب بنفسك

استقبل عمرًا. إذا كان بين 13 و18 شاملًا اطبع Teen، وإلا Other.

05

التنفيذ المتكرر — الحلقات

for وrange، وفكرة التكرار وشرط التوقف.

مثال 1 — for

for i in range(5):
    print(i)

مثال 2 — تكرار

for i in range(3):
    print("Python")

مثال 3 — while

n = 1
while n <= 3:
    print(n)
    n = n + 1

✍️ جرّب بنفسك

استخدم for وrange لطباعة 1 ثم 2 ثم 3.

✍️ جرّب بنفسك

استخدم for لطباعة Python أربع مرات.

06

الدوال واستدعاؤها والمعاملات

تعريف الدالة، استدعاؤها، المعاملات وreturn.

مثال 1

def hello():
    print("Hello")
hello()

مثال 2 — معامل

def greet(name):
    print("Hello", name)
greet("Ali")

مثال 3 — return

def add(a, b):
    return a + b
print(add(4, 5))

✍️ جرّب بنفسك

اكتب دالة square تعيد مربع العدد، ثم اطبع square(5).

✍️ جرّب بنفسك

اكتب دالة greet تطبع Hello واسم الشخص، ثم استدعها مع Ali.

✍️ جرّب بنفسك

اكتب دالة add تعيد مجموع عددين، ثم اطبع add(7,8).

07

مدخل إلى الصور ومعالجتها

الصورة كبيانات، الأبعاد، التدوير والتحويل إلى رمادي.

فتح صورة

from PIL import Image
img = Image.open("photo.jpg")
print(img.size)

تدوير

from PIL import Image
img = Image.open("photo.jpg")
rotated = img.rotate(90)
rotated.save("rotated.jpg")

رمادي

from PIL import Image
img = Image.open("photo.jpg")
gray = img.convert("L")
gray.save("gray.jpg")
هذا القسم يشرح أساسيات معالجة الصور كما تظهر في مسار الصف السابع. المختبر التفاعلي للصور سيضاف لاحقًا.
08

مشروع وتحديات

دمج المتغيرات والشروط والحلقات والدوال في مشروعات صغيرة.

🎯 لعبة التخمين

from random import randint
secret = randint(1, 10)
guess = int(input("Guess: "))
if guess == secret:
    print("Correct")
else:
    print("Try again")

🔢 تحدي الرقم الثلاثي

n = 485
a = n // 100
b = (n // 10) % 10
c = n % 10
print(a**2 + b**2 + c**2)

الناتج للعدد 485 هو 105.

🐢 تحدي الرسم

قسّم الشكل إلى خطوات صغيرة ثم اكتب برنامج Turtle يرسمه.

🏆 تحدي نهائي

اكتب برنامجًا يستقبل ثلاث علامات، يحسب المتوسط، ثم يطبع Excellent إذا كان المتوسط 90 فأكثر، Pass إذا كان 60 فأكثر، وإلا Fail.

طريقة التعلم

1. اقرأافهم الشرح بالعربية.
2. شاهدراجع أكثر من مثال.
3. اكتبجرّب الحل بنفسك.
4. افحصاعرف أين أخطأت.
